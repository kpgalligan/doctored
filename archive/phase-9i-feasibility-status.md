# Phase 9I — feasibility prerequisite decision

## Closing decision (2026-09-15)

**Work package 1 is closed with no pipeline selected. RVM is dropped.** The
repository's weight-license issue is still open and unanswered; the code is
GPL-3.0 and Rasterize is unlicensed (all rights reserved), so Rasterize could not
link it even if an evaluation grant covered the weights; and RVM is human-video
trained and trimap-free, so it cannot consume the brush guidance the assisted
protocol adds. No neural matting model is added to Rasterize. Apple Vision stays
the automatic prior. The conditional selection recorded below stands as history —
every hash, every comparison and every prerequisite finding is unchanged — but it
is no longer a pending decision. The gate is rescoped once in
[gate v2](phase-9i-gate-v2-status.md), which also records the information-bound
analysis, the assisted completion subset and the persistent storage locations.

The first work package in the [next-steps plan](phase-9i-next-steps.md) is a
prerequisite review. **No new candidate has been scored, and no pipeline is
currently eligible for the proposed comparison.** RVM MobileNetv3 is the one
preferred conditional pipeline after reviewing three established alternatives.
The exact checkpoint's applicable weight terms remain unresolved; the code
license and the author's inference examples do not settle that separate check.
This records an unmet project prerequisite, not a finding that use is prohibited.

9I, P7-12 and Phase 9 remain open. The original automatic 90-case gate, its five
failed candidates and the qualified execution foundation are unchanged. Advanced
controls remain disabled. This milestone does not add a model to Rasterize or
begin a sequence of further custom matting variants.
