Each row has one primary owner. References to supporting slices identify shared foundations or coordinated
integration; they do not require completion of the entire other slice and do not
transfer accountability. Split a row into smaller implementation assignments as
needed, retaining its ID and completion criteria. Mark it verified only after its

recovery work together, with independent pixel/coverage references where relevant.

to close a row. Declare new workload targets before qualification; a resized
substitute does not pass a failed native-size case.
A receiving phase cannot be marked complete while its assigned rows are open.

written reason. New exclusions discovered during later work need the same tracking.

## Contracts that remain intentional

These are not missing features to silently change while closing the register:

- The existing **flattened** conversion keeps its flattening behavior. P7-30 adds
  a separate choice; neither promotion nor later conversion recreates missing
  source precision or previously discarded editable state.
- Nearest quantization, canvas-anchored ordered RGB dithering, undithered alpha,
  latent-RGB handling and u16 write rounding remain explicit numerical contracts.
  Native-precision source samples and display/interchange conversions remain separate.
- A 256-bin histogram is a display choice, not a 256-level source. Exact endpoint
  counts and sampled-versus-complete statistics stay explicit as P7-07 adds scope.
- Legacy byte-valued Action arguments, genuinely byte-valued glyph/tip assets and
  model analysis outputs retain their declared precision. P7-05/06/11/13 add
  higher-precision authored controls/coverage without inventing input information.
- Profile conversion currently retains live parameters and can change the adjusted
  appearance. P7-22 adds a deliberate alternative; old documents must not change
  merely because a new color policy exists.
- Normalized encoded SDR remains the existing mode. P7-24/25 add separately
  versioned policies with their own gates, not an implicit change to all documents.
- Current limits, healing-domain/alpha/residual rules, error reporting and bounded
  refusals remain enforced until a replacement is qualified. Memory admission is
  not an OS RSS ceiling, even after P7-33 closes. No phase promises unlimited data.
