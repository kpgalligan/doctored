Doctored is a free, open-source image editor for photographers. It runs on an
Apple silicon Mac with macOS 15 Sequoia or later, and the download is a
notarized DMG.

<CardGrid stagger>
	<Card title="Photo editing" icon="star">
		Layers and masks, adjustment layers, selections down to hair, healing and
		content-aware retouching, Camera RAW, colour modes from Bitmap to Lab, and
		8-bit, 16-bit and 32-bit float documents.
	</Card>
	<Card title="Built-in assistant" icon="rocket">
		View ▸ Assistant opens a chat assistant that edits the open document,
		using your own Anthropic API key.
	</Card>
	<Card title="Agents over MCP" icon="puzzle">
		Settings ▸ MCP copies the command that adds the bundled `doctored-mcp`
		helper to Claude Code. The [MCP tool reference](/reference/mcp-tools/)
		lists every tool.
	</Card>
	<Card title="Open source" icon="open-book">
		Apache-2.0. The source, issues and releases are on
		[GitHub](https://github.com/kpgalligan/doctored).
	</Card>
</CardGrid>
