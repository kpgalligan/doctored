# Neural and generative models (ADR + living survey)

- **Status:** Accepted direction, 2026-10-13. The survey part is LIVING: re-research it before each model batch (see "Keeping it current"). Supersedes the "no neural model is added" line of [phase-9i-established-pipeline-decision.md](phase-9i-established-pipeline-decision.md).
- **Scope:** Generative Fill/Expand, Neural Filters, Sky Replacement; semantic masks.
- **Survey date:** 2026-10-13, by three web-research passes; the selection rows (Object select, Select by text, Select Sky, Hair/skin/clothes, Edge refinement) re-verified 2026-10-14 for M1. The model names, prices and timings below are their findings with sources. Items marked *unverified* were not confirmed against a primary source.

## Owner direction (2026-10-13)

- **Neural models are allowed generally.** The earlier "no neural model" line was a recommendation the owner accepted, not a policy they set.
- **Distribution:** Doctored is planned as free and open source, with optional in-app tips. Whether tips make use "commercial" under non-commercial model licences is an open question (see "Licence tiers").
- **Size is not a concern; performance is.** Offer the user more than one option where it helps, e.g. fast vs best.
- **Never a significant backend.** Each feature runs a local model on the Mac, or a cloud model through the user's own API key. Static files (converted model weights) on GitHub Releases or Hugging Face are not a backend.
- **Guardrails:**
  - nothing is uploaded without the user's consent (a per-provider opt-in, and a disclosure at first use);
  - the MCP agent may call a cloud generative tool only when a user setting allows it;
  - generated layers are tagged as generated in their metadata;
  - Neural Filters are decided filter by filter.

## Licence tiers

Three licences are separate: Doctored's own code licence (Apache-2.0 since 2026-10-13), each model's weights licence (plus its training data where documented), and the outputs.

| Tier | What qualifies | How it ships |
|---|---|---|
| **Clean** | Weights under Apache-2.0, MIT, BSD, or a licence like Meta's SAM License with no non-commercial clause; training data the publisher owns or licenses | May be the default; downloaded (or bundled) |
| **Clean, data-encumbered** | Permissive weights trained on academic-only datasets (Places365, DIV2K, ImageNet, DIS5K…) | **Owner decision pending (D1).** Recommended: treat as clean, downloaded not bundled, with the training data named in the model's info panel |
| **User-licensed** | Non-commercial or research weights (FLUX Non-Commercial, CC BY-NC, Qwen Research, S-Lab) | **Not offered until the tips question is settled (D4).** If it ever is: never bundled, off by default, downloaded from the official host only after the user accepts the licence in-app, labelled with its terms. Tips never unlock a model. |
| **Never** | Licences that exclude any product use, e.g. Apple's AMLR (Depth Pro, SHARP) | — |
| **Cloud** | Provider APIs with the user's own key | Provider terms bind the user. The app shows each provider's training and retention terms before first use |

Definitions that matter: CC BY-NC's NonCommercial is "not primarily intended for or directed towards commercial advantage or monetary compensation" ([CC](https://wiki.creativecommons.org/wiki/NonCommercial_interpretation)). ## Architecture decisions

1. **The app composites; the model only proposes.** No leading cloud editor guarantees unmasked pixels: OpenAI treats the mask as guidance, and Gemini's API has no mask parameter. Every generative path therefore does the following:
   1. crops the selection plus a context margin;
   2. scales it to the model's native size (about 1 MP);
   3. runs the model;
   4. scales the result back;
   5. blends it through the feathered selection onto a **new layer**, which is tagged as generated.

   Unmasked pixels are then exact for every provider, mask-less models become usable, and large photos work at native resolution.
2. **One provider interface per capability** (fill/expand/remove, segment, upscale, depth…), each with local and cloud implementations, chosen per feature in a Models settings pane. Each provider declares its native size, its mask support, its licence tier and its data terms.
3. **A model store.**
   - Weights download on demand, with a pinned SHA-256 and resumable transfers, into `~/Library/Application Support/Doctored/Models/`.
   - Each model records its licence acceptance and its training-data note, with a size and delete control in Settings.
   - Downloads come from the model's official host, or from the project's own GitHub Releases or Hugging Face page for converted Core ML files.
   - Test instances isolate the store with a `DR_MODELS_DIR` (app/CLAUDE.md, "Verification isolation").
   - First-party ids are `doctored/<name>` since the rename. A store's `rasterize--<name>` folder and `rasterize/<name>` acceptance are read in place (`ModelCatalog.legacyID(of:)`), never moved; a new download goes to `doctored--<name>`.
4. **Runtimes.**
   - **Core ML** on macOS 15 for small vision models.
   - **MLX through Swift packages** for diffusion: `flux-2-swift-mlx` and `mlx-lama-swift`, both MIT. These would be the app's **first third-party Swift packages** (D3).
   - **macOS 27-only APIs** (Vision `GenerateIterativeSegmentationRequest`, Core AI) are optional fast paths behind `if #available(macOS 27, *)`, with a macOS 15 path beside them.
   - Python-only runtimes (mflux) and GPL engines (Draw Things) are out: no helper processes in Python, and nothing GPL linked into the app.
5. **Cloud keys** are stored like the assistant's Anthropic key (a file in Application Support; test instances use dummy keys), one per provider. Requests go straight from the Mac to the provider.
   - The fal.ai provider always sends `X-Fal-Store-IO: 0` and a short output expiry.
   - Providers that train on API inputs by default (BFL, Stability, Gemini free tier) carry that warning in their consent sheet.

## Open owner decisions

- **D1. Data-encumbered weights: DECIDED 2026-10-13, treated as clean.** Permissive weights trained on academic-only data (MI-GAN/LaMa, Real-ESRGAN, DDColor, FBCNN, BiRefNet) are downloaded, not bundled, with the training data named in the model's info panel.
- **D2. Hosting converted weights: DECIDED 2026-10-13, yes.** Our own Core ML conversions of clean-tier models (MediaPipe, DA3, sky U²-Net) are published on the project's GitHub Releases or Hugging Face page, each with its licence and a pinned SHA-256.
- **D3. First third-party Swift packages: DECIDED 2026-10-13, adopt.** MLX and `flux-2-swift-mlx` (both MIT) are the local diffusion runtime, pinned by exact version and revision. They are added by the first batch that uses them (M3), not before.
- **D4. The tips question,** for the user-licensed tier. Deferred: no non-commercial model is offered until it is settled, ideally with a lawyer's reading.
- **D5. Doctored's own code licence: DECIDED 2026-10-13, Apache-2.0** (`LICENSE`). MIT, Apache and BSD runtimes are compatible. GPL engines (Draw Things) stay excluded.

## M0 shipped

- **Store.** `ModelCatalog.swift` is the catalogue as data (id, name, capability, version, files with URL, SHA-256 and size, runtime, minimum macOS, licence name, URL and tier, training-data note, `inference_bytes`, package). Its one entry is `apple/coreml-depth-anything-v2-small`, `DepthAnythingV2SmallF16.mlpackage`, pinned to commit `cfef6f6f2a70783dedc0bfae40cecbc2052285d3`, Apache-2.0, tier clean_data_encumbered. `ModelStore.swift` keeps `<dir>/<id>/<version>/`, `acceptances.json` (per id and version), the compiled `.mlmodelc` and `verified.json` (the ready marker); `ModelDownloader.swift` is the `URLSession` delegate seam: Range resume, streamed SHA-256, atomic rename, `MLModel.compileModel`. - **Settings.** ⌘, opens one card with Shortcuts and Models tabs; Download shows the licence card first for an unaccepted version. There is no MCP download tool: `list_models` reports the store.
- **Runtime.** `CoreMLRuntime.swift`'s `DepthEstimator` runs a compiled model on a `CGImage` with compute units `.all`, inside one admitted, cancellable `BackgroundWork` job.
- **Depth Blur.** `depth_blur.rs` is the kernel (the host's depth map in the params, a guided field through `edge_refine`, Lens Blur's disc at a depth radius, haze, the Develop Filter grade, Add Grain) on the existing filter routes at 8, 16 and 32 bits; the sheet, `depth_blur` over MCP and Actions (settings only, never the depth map or the model version) share `DepthBlurRun`.
- **Fixtures.** `scripts/fill_model_fixtures.py` fills `~/devel/doctored-fixtures/models` through the app's own downloader (network, once); `scripts/verify_depth_blur.py`, the jobs-probe's "depth blur sheet" and `scripts/depth-blur-admission/measure.py` read it.

## M2 shipped

M2a:
- **Command.** Edit ▸ Sky Replacement… (`SkyReplacementSheet.swift`) runs Select ▸ Sky's model once (`SkyReplacementRun.mask`), previews a ≤1024 px proxy of the layer through `dr_image_sky_replace` with a sky reduced once per pick (`SkyLibrary.previewImage`, f = min(1, 4·max(proxyW/sw, proxyH/sh))), and OK writes ONE new layer "Sky Replacement" directly above the layer and makes it active (`dr_doc_sky_replace` / `dr_precision_doc_sky_replace`, one job, one undo step). - **Admission.** `scripts/sky-replacement-admission/measure.py` (Release, 6000×4000, 8 and 16 bits): P = max(the M1 mask plan, `planned_bytes`) since M3a (it added the prepared display until then); the first measure missed at `SCRATCH_BYTES_PER_PIXEL` 20 and raised it to 38, and M3a's display-free gate raised it to 57 (records on the constant in `sky_harmonize.rs`).

Edge decontamination:
- **What.** "Decontaminate Edge" (sheet checkbox, on by default; MCP `decontaminate`, absent = off, so every Action recorded before it replays its old result) solves the old sky out of the edge pixels: `sky_decontaminate.rs` (kernel) sums the source's pure sky (m0 ≥ 0.98) and pure foreground (m0 ≤ 0.02) samples into two grids of at most 64×64 cells, and in the band (m0 > 0.02, 0 < m < 1) solves F = clamp((C − (1 − α)·B)/α) with α = 1 − m0, blending toward the nearby foreground below α = 0.25. `Prepared::foreground` feeds both outputs and the preview, so the light halo over a dark sky is gone (`tests/sky_decontaminate.rs`; drive gate DX8: 3,914 pixels darker by more than 2 codes, none brighter).

## Keeping it current

The model landscape changes monthly; Google retired two image models within weeks of this survey. Before each model batch:
1. Re-run the three surveys (local generative, cloud APIs, segmentation and filters).
2. Re-check each candidate's licence, its training data, its Apple-silicon runtime and its timing.
3. Update the table above and the survey date.
4. Update each provider's terms in its consent sheet.

The provider interface keeps a model swap a data change, not a redesign.
